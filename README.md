# Rent Unfiltered

更新日期：2026-10-31

Rent Unfiltered 是協助租屋者整理房源資訊、辨識缺漏並理解風險的競賽型 MVP。系統以 RHIR 整理資料、以 RRI 固定規則提供風險參考，並保留補件歷程。

> 本頁功能清單依 2026-10-31 `main` 程式碼靜態整理；這不代表 AI、雲端或擴充功能已在決賽設備完成操作確認。

## 專案簡介

租屋資訊常常分散在平台頁面、房東說法、看房筆記和截圖裡。很多重要條件不一定會被清楚揭露，例如能不能報稅、能不能遷戶籍、押金怎麼退、水電費怎麼算、消防與逃生是否安全。

Rent Unfiltered 想做的不是替使用者決定要不要租，而是把資訊攤開，讓使用者更容易看懂一間房子的條件與風險。

目前程式包含：

- **租屋表單**：把房源資訊整理成固定欄位。
- **RHIR**：Rental Housing Interoperability Resources 是本專案的租屋資料格式；欄位會記錄值、來源和揭露狀態，並可預覽、複製或下載 JSON。
- **版本紀錄**：可建立物件紀錄與補件版本，追蹤資料變化。
- **RRI**：依固定規則整理契約、費用、安全、權益與生活適配度五個面向；缺漏資訊可能呈現分數區間。
- **報告與個人策略**：詳情頁包含分析報告、待追問資訊和個人策略相關介面；AI Insight、策略生成與對話依賴 OpenRouter 等外部設定。
- **案例查詢**：程式包含依欄位和風險類型查詢案例的流程；需 Supabase 及可用資料，不能保證每個物件都有相符案例。
- **契約文件流程**：包含上傳、解析欄位候選與人工確認；需雲端設定，部分 OCR 選項可能付費。
- **Chrome 擴充功能 Demo**：可擷取使用者目前頁面的可見文字，送回指定網站的表單；需安裝擴充功能並可連線。
- **本機紀錄**：新增資料可保存於目前瀏覽器的本機儲存空間；網站資料不等於雲端備份。
- **Windows 桌面版**：程式包含 Electron 啟動與打包指令；桌面版本機資料與網站版分開保存，AI、契約解析及雲端資料仍需網路和服務設定。

專案附有示範租屋資料；它們不是使用者研究、外部驗證或市場統計。Rent Unfiltered 不替使用者決定要不要租，也不提供法律判定、安全保證或交易背書。

## 目前版本狀態

目前程式已有表單、資料紀錄、RHIR 檢視、版本流程、RRI、案例查詢、AI Insight、個人策略及契約文件等程式路徑。此清單描述的是程式內容，不是現場驗收結果。AI、案例、雲端保存與文件解析須視網路和服務設定而定。

較早建立的 [新功能前穩定化驗收清單](docs/新功能前穩定化驗收清單.md) 記錄了當時的檢查基準；若要確認目前分支狀態，應重新對照目前程式與服務環境。

## 進入網站後可以看什麼

網站內已經放了幾個適合第一次使用者閱讀的頁面：

- **首頁**：查看目前的租屋紀錄、欄位完整度、RRI 狀態與版本資訊。
- **新增租屋資訊**：建立新的租屋表單，送出後會轉成 RHIR 紀錄。
- **專案導引**：用比較短的方式說明專案動機、問題、解法與 MVP 定位。
- **物件詳情**：切換欄位、RHIR、契約文件、分析報告與策略分析內容。
- **擴充插件**：查看 Chrome 擴充功能的測試安裝及使用方式。
- **名詞解釋**：理解 RHIR、RRI、`disclosureStatus`、`sourceType` 等專案核心名詞。
- **資料管理**：程式包含 Supabase 上傳與管理頁；需先設定雲端服務。

如果只是想快速理解專案，建議順序是：

1. 先看 **專案導引**。
2. 回到 **首頁**，點一筆租屋紀錄看詳細頁。
3. 到 **新增租屋資訊** 建立一筆測試資料。
4. 再看 **名詞解釋** 與 **擴充插件**。

## Windows 桌面版

先安裝專案套件，再用下面的指令開啟獨立桌面視窗；不需要手動打開 Chrome：

```bash
npm install
npm run desktop
```

要產生可在本機雙擊的 Windows 版本：

```bash
npm run desktop:pack
```

完成後，開啟 `desktop-dist/Rent Unfiltered-win32-x64/Rent Unfiltered.exe`。請保留旁邊的整個 `Rent Unfiltered-win32-x64` 資料夾，不能只複製 exe。第一次安裝需要網路下載 Electron 執行環境。AI 分析、契約辨識和 Supabase 雲端資料需要網路；桌面版的 OpenRouter 功能還需要先在設定貼上自己的 API Key。網站版與桌面版的本機資料分開保存，不會自動搬移。

## AI Insight 設定

AI Insight 和策略分析會呼叫 OpenRouter。正式站需設定 Vercel 環境變數 `OPENROUTER_API_KEY`；本機開發則需可用的服務環境或依目前程式設定 API Key。沒有有效設定或網路連線時，生成可能失敗。

API Key 設定屬於服務使用條件，不要把金鑰寫進公開原始碼。AI 回覆是輔助說明，不重新計算 RRI，也不取代人工確認。

## Chrome 擴充插件 Demo 版

專案內已準備好測試用擴充插件壓縮檔：

```text
downloads/rent-unfiltered-capture-extension-v0.1.0.zip
```

這個插件可以擷取目前租屋頁面的可見文字，並把資料送回 Rent Unfiltered 表單，讓使用者先匯入，再補齊 RHIR 欄位。

### 安裝方式

1. 下載 `rent-unfiltered-capture-extension-v0.1.0.zip`。
2. 解壓縮 zip。
3. 打開 Chrome，進入 `chrome://extensions`。
4. 開啟右上角「開發人員模式」。
5. 按「載入未封裝項目」。
6. 選擇解壓縮後、裡面有 `manifest.json` 的資料夾。
7. Chrome 工具列會出現 `Rent Unfiltered Capture`。

### 使用方式

1. 開啟任一租屋頁面。
2. 確認 Rent Unfiltered 正式網站可開啟：`https://rent-unfiltered.vercel.app`。
3. 點 Chrome 工具列的 `Rent Unfiltered Capture`。
4. 按「擷取目前頁面」。
5. 確認文字有抓到後，按「送到 Rent Unfiltered」。
6. Rent Unfiltered 會開啟新增表單，並把可辨識欄位先預填。

### 目前限制

- 這是 demo 安裝方式，需要使用者開啟 Chrome 開發人員模式。
- 目前插件送回網址是正式部署站：`https://rent-unfiltered.vercel.app`。
- 正式給一般使用者前，仍建議上架 Chrome Web Store。
- 插件只擷取使用者主動點擊時該頁面的可見文字，不會自動背景追蹤瀏覽內容。

## 正式公開下載的方向
